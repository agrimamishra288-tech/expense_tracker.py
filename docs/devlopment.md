I built this project step by step while slowly learning how Python file handling works. I started by creating a simple menu system in VS Code and then added one feature at a time.

First I wrote the add expense function because that was the easiest part for me to understand. After that I added viewing expenses and reading data back from the CSV file. Testing each part as I went helped me understand where I was making mistakes.

I also created a docs folder for the markdown files and took screenshots once the main features started working. Then I set up Git and made multiple commits while pushing everything to GitHub. This project helped me learn the basics of version control and organizing files in a cleaner way.
