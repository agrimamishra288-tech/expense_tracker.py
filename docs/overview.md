Project Overview

This is a simple personal expense tracker that I built to understand how Python works with files and basic data handling. The program lets me add expenses, view all of them, check the total amount spent, and filter by category. All the data is saved in a CSV file which makes it easy to store and read later.

I made this project step by step in VS Code and used Git and GitHub to manage the versions. Working on this helped me learn how to write cleaner code, organize folders, and use Git commands properly. It is a small project but it helped me gain confidence as a beginner.
