# Personal Expense Tracker
Author: Agrima Mishra  
Roll No: 2501010207  
Date: 2025-11-23  

## Description
This is a simple command line program that helps record, view and analyse personal daily expenses.  
It stores all data in a CSV file and shows totals and category wise spending.

## How to Run
1. Make sure Python 3 is installed  
2. Run:

python expense_tracker.py


## Features
- Add expense  
- View all expenses  
- View total spent  
- Filter by category  
- Saves data in CSV file
