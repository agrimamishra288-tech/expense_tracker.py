Author: Agrima Mishra

## Description
This is a simple command line program that helps record, view and analyse personal daily expenses.  
It stores all data in a CSV file and shows totals and category wise spending.

## Installation

- Install Python on your computer if you do not have it.
  
  
- Download or clone the project from GitHub.
  
  
- Open the folder in VS Code.


- Make sure the file expenses.csv is in the project folder. The program will create it if it does not exist.


- Open a terminal in VS Code.



## Usage

Run the program with:

python expense_tracker.py


You will see the menu with the following options:


- Add a new expense


- View all saved expenses


- Check the total money spent


- View expenses by category


- Exit the program


Follow the instructions shown on the screen.
All your expenses will be stored in expenses.csv.


## How to Run
1. Make sure Python 3 is installed  
2. Run:

python expense_tracker.py


## Features

- Add expense 
- View all expenses 
- View total spent  
- Filter by category  
- Saves data in CSV file
